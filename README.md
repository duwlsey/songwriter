# 나도 작곡가

초등학생이 4/4박자 여덟 마디를 만들고, 노랫말과 뮤직비디오를 꾸미는 수업용 웹 앱입니다.

## 먼저 체험하기

Node.js가 설치되어 있다면 이 폴더에서 `npm run dev`를 실행하고 [로컬 앱](http://127.0.0.1:4173/)을 엽니다. 첫 화면의 **둘러보기**에는 편집할 수 있는 예시 곡이 있습니다. 둘러보기의 변경은 페이지를 열어둔 동안 유지됩니다.

저장을 시험하려면 학생 화면에서 학급 단어 **연습**, 숫자 **3101**로 접속합니다. 작품을 저장하고 첫 화면으로 돌아간 뒤 같은 코드로 접속하면 마지막 저장본이 열립니다. 테스트 작품은 이 컴퓨터의 `.test-song.json`에 기록됩니다.

로컬 주소에 접속할 수 없다면 `저장 테스트.html`을 Chrome 또는 Edge에서 직접 열어 같은 코드로 접속하세요. 이 파일의 작품은 브라우저에 저장되므로 같은 브라우저에서 같은 파일을 다시 열면 이어 할 수 있습니다.

## 학교별로 복제하고 연결하기

1. 저장소를 포크하거나 다운로드합니다. 교사 계정에 사용할 Firebase 프로젝트를 만들고 Authentication의 이메일/비밀번호 로그인을 켭니다. 프로젝트 설정의 웹 API 키를 복사합니다.
2. `npm run build:apps-script`를 실행합니다. 새 Google Apps Script 프로젝트에 `apps-script/Code.gs`를 복사하고 HTML 파일 `Index`를 만들어 생성된 `apps-script/Index.html` 내용을 붙여넣습니다. 프로젝트 설정에서 매니페스트 표시를 켜고 `apps-script/appsscript.json`을 복사합니다. 연결된 Google Cloud 프로젝트에서 Drive API를 사용 설정합니다.
3. Apps Script 프로젝트 설정의 스크립트 속성에 `AUTH_KEY`를 추가합니다. 편집기에서 `install_`을 한 번 실행하고 권한을 승인합니다. 운영자 Drive에 비공개 저장 폴더와 스프레드시트가 만들어지고, 매일 만료를 처리하는 트리거가 설치됩니다.
4. Apps Script를 웹 앱으로 배포합니다. **다음 사용자로 실행**은 배포자, **액세스 권한**은 익명 학생이 접근할 수 있는 **모든 사용자**를 선택합니다. 학교 Workspace 설정에 따라 이 옵션이 제한될 수 있습니다. `/exec` 주소에서 교사 회원가입과 학생 접속을 확인합니다.
5. GitHub Pages를 쓸 경우 포크의 `config.js`에서 `webApp` 값에 위 주소를 넣고 저장소 루트를 Pages에 게시합니다. 이 주소에서 둘러보기를 바로 열 수 있고 학급 작업은 연결된 Apps Script 앱에서 진행합니다. 앱을 갱신할 때는 HTML을 다시 생성한 뒤 Apps Script 배포 버전도 갱신합니다.

학교마다 위 절차로 독립된 저장소를 만들 수 있습니다. 같은 설치를 여러 교사가 쓰면 교사별 학급 접근은 분리되고, Drive 공간과 Apps Script 한도는 설치 단위로 공유됩니다. GitHub에는 앱 소스만 올리고 작품 스프레드시트나 파일은 올리지 않습니다.

## 학급 운영

- 교사가 학급 단어를 만들고 학년·반·번호 범위 또는 4자리 범위를 입력합니다. 예를 들어 3학년 1반의 1~5번은 `3101`~`3105`입니다. 학생은 학급 단어와 발급된 숫자를 입력합니다.
- **불러오기**로 마지막 저장 시점의 단계와 날짜를 새로 확인합니다. 산출물 관리에서 각 단계를 읽기 전용으로 열거나 결과를 다운로드합니다.
- 작품과 사진은 첫 저장 시점을 기준으로 두 달간 앱에서 열 수 있습니다. 만료된 작품 파일은 다음 일별 실행에서 Drive에서 영구 삭제됩니다. 번호는 남아 있고 새 작품을 시작할 수 있습니다.
- 음표 높이를 바꾸거나 음표를 삭제하면 해당 음표의 가사가 지워집니다. 곡 설명이 입력되고 저장된 뒤 2단계로 갈 수 있으며, 여덟 마디가 모두 4박이어야 3단계로 갈 수 있습니다.
- MP4는 기기의 브라우저 녹화 지원이 필요하고 재생 길이만큼 걸립니다. 제작 중에는 창을 열어 두세요. 영상에 넣을 사진은 이미지 파일이나 ZIP으로 올립니다. ZIP과 MP3는 CDN에서 도구를 내려받습니다.
